구글 시트 연동 가이드 & Apps Script 코드 복사

  1. 새 구글 스프레드시트를 열고 상단 메뉴 [확장 프로그램] → [Apps Script]를 클릭하세요.
  2. 편집기의 기존 코드를 모두 지우고, 아래 [📋 Apps Script 코드 전체 복사] 내용을 붙여넣은 뒤 저장(Ctrl+S)하세요.
  3. 오른쪽 위 [배포] → [새 배포] → 유형: [웹 앱], 액세스 권한을 [모든 사용자]로 선택하고 배포하세요. (기존 배포 수정 시에는 반드시 [배포 관리 → ✏️ → 새 버전]으로 배포해야 적용돼요!)
  4. 발급된 웹 앱 URL (끝이 /exec인 주소)을 복사해 위 세이브포인트 입력칸에 연결하면 끝이에요 뀽!
